# Dizzah Media — SEO & Indexing

Imeongezwa:

- `robots.txt`
- `sitemap.xml`
- `feed.xml` (RSS)
- Canonical URL kwenye homepage na article page
- Open Graph na Twitter card metadata
- Schema.org `NewsMediaOrganization` na `NewsArticle`

## Google indexing

SEO files hufanya site iwe crawlable lakini haziwezi kuilazimisha Google kui-index papo hapo. Baada ya deployment kuwa live:

1. Fungua Google Search Console.
2. Add property ya domain/URL ya site.
3. Thibitisha ownership.
4. Fungua **Sitemaps** na submit `sitemap.xml`.
5. Tumia URL Inspection kwa homepage na request indexing.

Sitemap ya sasa inalenga URL ya deployment ya Manus. Ikiwa custom domain itawekwa baadaye, badilisha URLs zote ndani ya `robots.txt`, `sitemap.xml`, `feed.xml`, canonical tags na structured data ziende kwenye domain mpya.
